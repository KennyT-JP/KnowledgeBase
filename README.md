# Knowledge Base（ナレッジベース）

このリポジトリは、複数プロジェクト共通のドキュメント、監査手順、ベストプラクティスを一元管理します。

## 格納ドキュメント

### 1. ナレッジベース.md
**ベストプラクティス集。設計・実装の前に読む。**

- 仕様編：認証設計、メール確認、権限表示など製品レベルの判断
- 技術編：Firebase Realtime Database、Firestore、セキュリティ、パフォーマンスなど技術選択

関連：[アンチパターン集.md](アンチパターン集.md)（本書の各項目の根拠になった失敗事例）

### 2. アンチパターン集.md
**実際に踏んだ失敗を「事象→原因→回避方法」で記録。**

データ設計、権限・認証、プロトコル、実装パターンなど、複数プロジェクトで繰り返された失敗を防ぐ。

- 新しい機能に着手する前に関係する章に目を通す
- 失敗を踏んだら一般化して追記する

関連：[ナレッジベース.md](ナレッジベース.md)（こうすべき側）

### 3. 監査手順.md
**Session Concierge ゼロベース監査の手順書。**

- 重点6項目（セキュリティ、テスト網羅性、実装一致、コード品質、マニュアル、パフォーマンス）
- 観点ごとに独立したエージェントを起動し、最後に結果を突き合わせる方法論
- 各重点項目の全量リスト作成方法と確認項目

---

## 使い方

### 開発時
新しい機能・変更に着手する前に：
1. [ナレッジベース.md](ナレッジベース.md) で関連する章を読む
2. [アンチパターン集.md](アンチパターン集.md) で該当の失敗パターンを確認

### 監査時
Session Concierge のゼロベース監査は [監査手順.md](監査手順.md) に沿って実施。

---

## 更新方針

- 新しい知見は一般化して追記する
- 失敗を踏んだら、プロジェクト固有の記述は出典欄に留め、内容は汎用化する
- ドキュメント間の関連は [[参照リンク]] で示す
